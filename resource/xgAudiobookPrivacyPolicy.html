引言

欢迎使用晓哥读书（以下简称「本应用」）。本应用是一款在您设备上使用的阅读和听书工具：书籍由您自行导入或来自安装包内的公版名著示例。本应用不提供账号注册/登录，也没有书籍内容服务器，不会把您导入的书籍正文同步到开发者服务器。

本政策说明我们如何收集、使用、存储和保护与您有关的信息。请在使用前阅读。如您不同意，请停止使用本应用。

个人信息处理者：晓哥读书（个人开发者）
联系邮箱：xgjyjy@gmail.com

一、我们如何收集和使用信息

我们遵循合法、正当、最小必要原则。下列信息在对应功能场景下才会处理；您拒绝提供仅影响该功能，不影响在本机阅读、听书已导入的内容。

1.1 本机阅读、听书与书架（核心功能）

为在本机保存书籍、分页阅读、听书播放和进度续读，我们会在您的设备本地处理：您导入的书籍文件与解析后的正文、书名/作者、封面、章节目录、阅读进度、听书进度与播放设置、主题/亮度/字体等阅读偏好。上述内容默认只保存在本机数据库和沙盒目录，用于实现阅读和听书，我们不会将其上传到自有服务器。

听书使用系统或设备上的语音合成能力，在本机把文本转为语音。我们不会把听书文本发到自有服务器。若系统语音引擎另有联网行为，以其提供方规则为准。

书架和听书中的搜索只在本机已导入书籍中筛选，搜索词当前不会上传，也不会作为云端个性化推荐依据。本应用不对您做基于画像的个性化内容推荐或个性化广告。

1.2 导入书籍

（1）本地导入、系统分享、「用其他应用打开」：在您选择或分享文件后，将 txt、epub、pdf、doc/docx 等文件复制到本应用沙盒并解析。文件由您提供，保存在本机。

（2）粘贴导入：仅处理您主动输入或粘贴的文本。我们不会在后台读取剪切板。

（3）图片导入（文字识别）：经您同意后使用相机拍摄或从相册选图，在设备上识别文字并生成书籍。iOS 使用系统 Vision；Android 使用 Google ML Kit 中文文字识别（端侧处理）。图片与识别结果保存在本机，我们不会把图片发到自有服务器。

（4）扫码导入：经您同意后使用相机扫描二维码，将码内文本导入为本机书籍。识别在本地完成。

（5）WiFi 传书：仅在您打开该页面时，本机临时开启局域网网页服务，供同一 WiFi 下的电脑向手机传文件。期间可能在局域网页面展示设备名称或型号、本机临时文件列表，并使用本地 IP 与本地网络/组播能力。该服务不面向公网。请勿在不信任的网络使用；离开页面后服务会关闭。

（6）「向晓哥要一本」：从安装包内的公版名著示例复制到书架，不经过开发者服务器。

（7）WiFi 传书页可能把局域网地址写入剪切板，便于您粘贴到电脑浏览器。这是您可感知的写入，不是后台读取剪切板。

1.3 意见反馈

您提交意见反馈时，我们会收集您填写的反馈类型、正文，以及您自愿填写的联系方式（邮箱、手机号或 QQ）。如您选择上传图片，相关图片会作为附件一并发送。上述信息通过电子邮件发送到开发者邮箱，仅用于处理反馈、修复问题，不会用于营销短信或电话推销。

联系方式和反馈图片属于您自愿提供；不提供仍可使用阅读、听书等核心功能。

1.4 阅读字体（可选）

若您选择下载在线字体，本应用会向 Google Fonts、jsDelivr、GitHub 等字体分发地址请求字体文件。对方可能因此获得您的 IP 地址、User-Agent 及所请求的文件名。字体文件缓存在本机。您可以继续使用系统字体，无需下载。

1.5 查看本政策

在应用内打开本政策时，页面由 GitHub Pages 托管，访问过程中 GitHub 可能记录 IP 地址等常规访问日志。您也可以用系统浏览器打开同一链接。

1.6 我们不会收集的信息

我们不会收集 IMEI、IMSI、MAC 地址、硬件序列号、IDFA、通讯录、短信、精确位置、应用安装列表、通话状态，也不会接入广告联盟或第三方统计分析 SDK。本应用不提供直播、游戏、账号体系或内容社区。

二、设备权限

权限只在您使用对应功能时申请，可在系统设置或本应用「设置 - 权限设置」中关闭。关闭后相关扩展功能不可用，不影响已导入书籍的阅读和听书。

三、本机存储与 Cookie

本应用使用设备本地数据库和偏好设置保存书籍、进度和显示设置，以便您下次打开时继续使用。这不是浏览器 Cookie，数据留在本机。

您可在「设置 - 清理缓存」删除缓存，并在书架删除书籍。卸载应用将删除沙盒内数据（系统另有备份的除外）。

四、共享、转让与公开披露

我们不会出售您的个人信息。除下列情形外，不会向第三方提供您的个人信息：

（1）您主动提交意见反馈时，邮件及附件会通过电子邮件发送到开发者邮箱；

（2）您主动下载在线字体或查看本政策时，相应网络服务提供方可能收到访问日志；

（3）法律法规规定或有权机关依法要求。

本应用无兼并收购计划中的数据转让安排。如将来发生主体变更，我们会重新告知并征求同意。

五、保存地点与期限

书籍、进度和阅读设置保存在您的设备本地，保存至您删除该书籍、清理相应数据或卸载应用。

意见反馈邮件保存在开发者邮箱中，位于中华人民共和国境内，保存至反馈处理完毕；如法律要求更长保留期限的，从其规定。处理完毕后，我们不会将其用于其他目的。

字体缓存保存在本机，您可清理缓存删除。

六、信息安全

本机数据使用系统提供的应用沙盒保存。意见反馈通过电子邮件发送。请妥善保管设备，勿在越狱/root 或不可信网络环境下使用 WiFi 传书。请勿在反馈中提交与问题无关的敏感信息（如身份证号、银行卡号）。

七、您的权利

本应用不提供注册登录，因此不涉及账号注销。您可以：

（1）查阅、删除本机书籍：在书架中删除；

（2）更正阅读/听书设置：在阅读器、听书页或设置中修改；

（3）撤回权限：系统设置，或本应用「设置 - 权限设置」；

（4）清除缓存：「设置 - 清理缓存」；

（5）停止使用：卸载本应用。

如需我们协助处理已发送的意见反馈邮件，请向 xgjyjy@gmail.com 来信，我们原则上在 15 个工作日内答复。因书籍正文仅存在您的设备上，开发者无法远程删除您手机里的书，请在本机操作。

八、未成年人

本应用不以不满十四周岁的儿童为目标用户。若您是未成年人，请在监护人同意和指导下使用，并仅导入有权使用的内容。我们不会主动收集儿童的个人信息。如监护人发现儿童在未经同意的情况下向我们发送了反馈信息，请联系上述邮箱，我们会尽快删除相关邮件。

九、政策更新

功能或处理方式发生变化时，我们会更新本政策并调整文首日期。更新后的政策在本页面公布。如发生处理目的、方式或种类等重大变更，我们会在应用内提示。请以本页面最新版本为准。

十、如何联系我们

隐私问题、投诉或行使权利，请发送邮件至 xgjyjy@gmail.com。我们将在 15 个工作日或法律要求的期限内答复。

您也可以在本应用「设置 - 隐私政策」查看本政策。
